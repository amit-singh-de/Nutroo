# Your AI Assistant for Meal Prep Especially for GYM lovers.
## Meal Prep has never been easier.


## Features - 
1. Can Search Web for Recipies.
2. Can Rank Suggested Recipies based on Nutritional Value.
3. Every Recipies Suggested will be based on indregients available from user.
4. If User Submits their Daily Nutrional Requirements then Can also Suggest Daily , bi-weekly , weekly meal plan accordingly.

## Flow -
- User Submits their Daily Nutrional Requirements. [Optional]
    eg - Protein : 200 g , Carbs : 200 g , Fat : 40 g , Total Calories : 1500 KCAL.
- User Sends Available Indregients.
- Agents Searches the web for recipies that can be made from available list of Available Indregients
- Stores All the Search Results for Future Queries.
- Ranks the Recipies based on Nutritional Values.
- Compares the Users Nutrional Requirements vs Recipies and suggests.
- If User Decided to make the Recipe then deduct the Numbers from daily Quota for next Meal Suggestion.
